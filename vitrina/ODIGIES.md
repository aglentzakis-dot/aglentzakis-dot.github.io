# Βιτρίνα GlenApps — έκδοση 6.1.0

## Τι είναι
Εργαλείο για να φτιάχνει κάθε μάστορας τη δική του σελίδα με έργα και φωτογραφίες.
Όλα φυλάγονται ΜΟΝΟ στη συσκευή του χρήστη. Η σελίδα ανεβαίνει στον ΔΙΚΟ ΤΟΥ δωρεάν λογαριασμό.
Οι GlenApps δεν φιλοξενούν και δεν βλέπουν κανένα στοιχείο.

## Αρχεία
- index.html — η εφαρμογή (επεξεργασία, προβολή, δημοσίευση, αντίγραφα)
- sw.js — άνοιγμα αμέσως από τη συσκευή, και χωρίς σύνδεση (κανόνας GlenApps)
- manifest.webmanifest, icon.svg — εγκατάσταση στο κινητό
  (το icon.svg είναι προσωρινό: να μπει το αυθεντικό G των GlenApps)

## Δοκιμή
Ανέβασέ τα σε αποθετήριο GitHub Pages (π.χ. φάκελος vitrina) και άνοιξε τη διεύθυνση από το κινητό.

## Τι κατεβάζει ο χρήστης με «Λήψη έτοιμης σελίδας»
vitrina-selida.zip: index.html, stil.css, skript.js, politiki-aporritou.html,
_headers (κεφαλίδες ασφαλείας), fotografies/*.jpg (χωρίς GPS/στοιχεία κάμερας).
Ανεβαίνει ως έχει στο Cloudflare Pages με «Upload assets».

## Έκδοση
Σε κάθε αλλαγή: meta app-version, APP_VERSION (index.html) και CACHE (sw.js) μαζί.
